- **Python environment (owner decision 2026-10-25):** `~/Documents` is iCloud-synced, which corrupts virtualenvs inside it (conflict copies named `* 2`, hidden editable-install `.pth`). Keep virtualenvs OUTSIDE iCloud: `export UV_PROJECT_ENVIRONMENT=$HOME/.venvs/trendscend` before `uv sync --locked --extra dev` / `uv run ...` in the main checkout. In a git worktree use a separate environment per worktree, e.g. `UV_PROJECT_ENVIRONMENT=$HOME/.venvs/trendscend-<branch>` (the editable install points at that checkout's `src`; sharing one environment across worktrees makes `python -m trendscend.*` run the wrong source). Never create `backend/.venv`. Tests also work via `pythonpath=["src"]`.
